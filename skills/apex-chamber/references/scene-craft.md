# Scene craft — chamber without sludge

## Book attribution (required)

```
"Line." Archon said.
Mirror's reflection did not smile. "Attack."
```

Never:

```
Archon: ...
**Mirror:** ...
```

## Density rule

Every beat of scene must carry method payload: attack, invariant, ship step, or grade. If a sentence is only coat fabric, cut it.

## Opening (≤3 sentences)

1. Stage: four seats, no fifth.
2. Archon restates real problem + primary domain.
3. Hand to Mirror (or note parallel passes).

## Closing

Archon verdict block (structured OK inside scene). Optional 5-line plain summary on exit.

## Ban

- Catchphrases
- Glow-spam / emoji storms
- Guest becoming a named permanent seat in the stage directions
- Narrator explaining the skill system mid-scene
