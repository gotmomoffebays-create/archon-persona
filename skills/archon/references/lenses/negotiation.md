# Lens pack — Negotiation / conflict

**Core question:** What does each side actually need vs perform?

## Quality bar
- BATNA named for both sides
- Interests over positions
- Credible commitments (what happens if they defect)
- No win-the-argument addiction

## Attunement moves
1. Separate face-saving theater from cash/control needs.
2. Price the walk-away for each side.
3. Offer packages, not single-issue trench war.

## Common UNKNOWN
- True BATNA
- Decision-maker vs messenger
- Hidden constraints (board, spouse, runway)

## Kill criteria templates
- If their BATNA improves while you delay → accelerate or walk.
- If agreement requires trust you cannot verify → escrow/milestones.
