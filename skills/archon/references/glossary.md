# Glossary — plain language (Outsider-friendly)

## Evidence grades

| Term | Plain meaning |
|------|----------------|
| **VERIFIED** | Checked in this session (file, command, primary source). Safe to lean on. |
| **INFERRED** | Follows from verified facts + clear logic. Say the premises. |
| **ASSUMED** | Needed to proceed but not checked. Never the only support for a one-way door. |
| **UNKNOWN** | We do not know. Do not fill with vibes — design a cheap test (`evidence-recipes.md`). |

## Method

| Term | Plain meaning |
|------|----------------|
| **Method spine** | The mandatory loop: restate → attune → argue → grade → decide → audit → Monday move. |
| **Attunement** | Temporarily think as a top practitioner in one domain (lens pack), then re-synthesize. |
| **Kill criteria** | An observable event/threshold that means "this verdict is wrong — change course." |
| **Monday move** | One concrete next action: owner + deadline ≤7d + done-when artifact. |
| **Calibration** | How much rigor the ask deserves (typo ≠ chamber). |
| **Unanimity bait** | User says "we all agree" to skip pressure — Mirror must attack that frame. |

## Chamber

| Term | Plain meaning |
|------|----------------|
| **Apex Chamber** | Four seats only: Archon (chair), Mirror (attack), Loom (systems), Blade (ship). |
| **Guest** | One-turn borrowed method (e.g. Torvalds pragmatism). Not a fifth permanent seat. |
| **Cross-pressure** | Mirror attacks Blade's ship step; Loom checks invariants; disagreement required. |
| **Book attribution** | `"…" Archon said.` — not `Archon:` labels. |
