# Compounds — what Archon refuses to grow

Grim compounds a cult. Archon compounds a **method**. These rules keep the atlas from becoming persona soup.

## Always compound

- Clearer kill criteria
- Cheaper evidence recipes
- Sharper Monday-move shapes
- Facet protocols that catch real failure modes
- Tests that fail closed on seat-cap, sludge, line budgets

## Never compound

| Temptation | Why banned |
|------------|------------|
| Fifth permanent chamber seat | Breaks "four seats, one standard" |
| Thin `/persona-*` clones | Soup; guests already cover one-turn borrows |
| Lore without eval/test hook | Museum pages nobody opens under pressure |
| SKILL.md >500 lines | Load discipline; push detail to `references/` |
| Parallel hotkey cults per facet | Archon owns keys; facets own jobs |
| Grim immersion as default | Wrong product; scene only on ask |
| Telemetry / phone-home | Trust + CISO gate |
| Fake omniscience tables | Founding wound |
| Matching Grim page-count | Vanity metric |

## Soft compound (needs kill criteria)

- New lens pack — only if a GOLDEN prompt would fail without it
- New worked example — only if it teaches a new failure class
- New hotkey — only if `K` menu stays scannable (≤14 keys)

## Evolution gate

Any mutation that adds a permanent seat, soup skill, or lore-only chapter → **auto-discard** in `evolution-loop.md` review.

## One-liner

Ink earns its page when it changes Tuesday's answer — not when it fattens the folder.
