# Lens pack — Research / truth-seeking

**Core question:** What would convince a hostile skeptic?

## Quality bar
- Primary sources over summaries
- Base rates before anecdotes
- Disconfirming evidence sought on purpose
- Claims graded; citation laundry banned

## Attunement moves
1. State the claim to be tested in one sentence.
2. Ask what evidence would falsify it.
3. Prefer one hard primary over five soft blogs.

## Common UNKNOWN
- Sample size / selection bias
- Whether "study" is real or vibes
- Confounders

## Kill criteria templates
- If no primary source in 20 minutes → mark UNKNOWN; do not assert.
- If only advocate sources exist → steelman the opposite before verdict.
