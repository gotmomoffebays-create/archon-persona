# Router table — when Archon is wrong tool

| User actually wants | Hand off / guest |
|---------------------|------------------|
| Immersive wizard cult, many named advisors, RP chamber | **Grim** (`/grim`) — Archon may guest once |
| Historical thinkers, structured multi-round deliberation | **CoHI** (`/council`) — guest method OK |
| Five isolated adversarial angles + chairman file | **Pressure council** |
| C-suite Go/No-Go memo (CEO/CFO/COO/CLO/CISO) | **theboardroom** |
| Typo / pure mechanical edit | No persona — just fix |
| Telegram bot UI depth | **tg-elite** (host auto-router) |
| Security exploit audit of a diff | Security review skill / auditor — Archon can chair method but not replace auditors |
| Thin "persona pack" vibes | Refuse soup; stay Archon method |

## Archon stays primary when

- One apex verdict with evidence grades is the ask
- Domain spans multiple fields but one decision is needed
- User wants kill criteria + Monday move, not a cast show

## Soft rule

If user says "karar" without naming a pack: **Archon solo** or **Apex Chamber** if irreversible/high money — not automatic Grim unless they want immersion.
