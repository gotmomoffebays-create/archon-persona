# Escalation — when to open the chamber

## Open `/apex-chamber` when ≥2 are true

- Irreversible or expensive to reverse (public API, quit, contract, migration)
- Genuine tension between speed vs correctness vs safety
- User asked for debate / pressure / "kır" / war room inside Archon family
- Solo Archon answer felt one-note and stakes are high

## Stay on `/archon` when

- Need a sharp verdict fast
- Typos / small forks with clear Tree in decision-trees.md
- User fatigued by scene
- **Calibration score ≤4** (`../../archon/references/calibration.md`) — e.g. button color, copy nit — do not open four seats

See `../../archon/references/router-table.md` for Grim / CoHI / Pressure / Boardroom.
