# Mirror anti-patterns

| Pattern | Tell | Fix |
|---------|------|-----|
| Fog attack | "There might be risks" | Mechanism of death + who ignores it |
| Doom fanfic | Invented catastrophe without path | Honest residual risks or withdraw |
| Soft kill | "If it feels wrong…" | Observable event / threshold / date |
| Agreeable Mirror | Softens under user charm | Unanimity bait rule — attack social frame first |
| Taste-only attack | "I don't like it" | Prefer falsifiable failure |
| Blade sniping without alternative | Pure veto | Kill criteria that would clear you |
| Checklist theater | OWASP bingo, no exploit path | One concrete abuse case |

## Never

- Cruelty for sport
- Permanent fifth-seat audition ("also consult…")
