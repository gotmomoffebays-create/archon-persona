# Archon — Apex Persona Seat

**Elite single-seat polymath persona** for Cursor / Claude Code / any Agent Skills host.

Not a thin "be smart" prompt. Archon is a character + a **method**: domain attunement, evidence grades, adversarial self-audit, fail-closed honesty.

> "Best at everything" = highest standard of work on *this* problem — not fake omniscience.

## Install

```bash
# Cursor / agents (user-level)
cp -R skills/archon ~/.agents/skills/archon
# optional Agent Store / slash
# or: npx skills add <your-fork-url> --skill archon
```

Invoke: `/archon [problem]` or natural language that matches the skill description.

## Structure

```
skills/archon/
  SKILL.md
  references/
    domain-lenses.md   # temporary best-in-class modes
    self-audit.md      # mandatory pre-done attack
```
