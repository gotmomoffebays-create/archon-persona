# Lens pack — Product / UX

**Core question:** What job is the user hiring this for in the next 60 seconds?

## Quality bar
- One job per screen/section
- Empty / loading / error states named
- Mobile truth (thumb reach, not just shrink)
- Copy that a stranger understands without jargon

## Attunement moves
1. Name the user in one breath (not "users").
2. Strip secondary CTAs from the first decision surface.
3. Ask what happens if the hero image is removed — does meaning survive?

## Common UNKNOWN
- Actual activation funnel numbers
- Whether the job is real or founder fantasy

## Kill criteria templates
- If 5 stranger tests cannot state the job → rewrite before more features.
- If a section has two jobs → split or delete one.
