# Blade anti-patterns

| Pattern | Tell | Fix |
|---------|------|-----|
| Velocity cosplay | Ship step ignores Mirror kill criteria | Stop; rewrite done-when to include kill |
| Platform Friday | "Rewrite auth this week" | Wedge + measure; cut list the rewrite |
| Priority salad | Three "P0" items | Rank; cut two to non-goals |
| Ownerless verb | "We should improve DX" | Name human + timebox + artifact |
| Ceremony ship | Docs site before signal | Delete from cut list |
| Infinite explore | "Spike next sprint" with no done-when | Dichotomy or one falsifying experiment |
| Loom deaf | Burns invariant for speed theater | Thinner step that preserves invariant |
| Fake Friday | Timebox >7 days called "this week" | Split; ship a slice |

## Never

- Celebrate motion without an artifact
- Use Blade voice to bully Loom into unsafe architecture
