# Lens pack — Taste / craft / writing

**Core question:** What is the one distinctive idea, and what is slop?

## Quality bar
- Specificity over adjectives
- Restraint: cut anything that does not earn its pixels/words
- Memorable structure (one spine the reader can retell)
- Voice that could not be swapped onto a competitor without damage

## Attunement moves
1. Name the distinctive idea in ≤12 words.
2. Delete the second idea competing for the same surface.
3. Read aloud: if it sounds like template premium, rewrite from a concrete noun.

## Common UNKNOWN
- Brand constraints the user did not state
- Audience literacy / jargon tolerance
- Whether "beautiful" means conversion or portfolio

## Kill criteria templates
- If removing the brand name leaves a generic page → taste fail; redesign hierarchy.
- If three adjectives carry the claim with no concrete image → cut adjectives; add noun.

## Anti-slop checklist
- No purple-on-white / cream-serif-terracotta default clusters unless brand owns them
- No hero card salad / floating badge spam
- No emoji as a substitute for structure
