# Archon Deepen — Spellbook Without Cult

## Problem Statement
How might we make Archon a spellbook-grade elite persona that users invoke daily, without growing a Grim-sized cult roster?

## Recommended Direction
**Grow the Atlas, freeze the Chamber.** Depth via `references/` (lenses, hotkeys, worked bars, failure modes, self-audit, method spine). Apex Chamber stays four seats. Guests = temporary invitations only. Daily habit = hotkey + P0–P4; chamber = escalation.

## Key Assumptions
- Daily trigger is method, not theater
- Spellbook depth beats seat count
- Four-seat cap is felt as strength
- Hotkeys drive retention
- SKILL.md stays under 500 lines

## MVP Scope (this pass)
1. method-spine + onboarding + guests
2. Expand Archon refs + facet references
3. Hotkey micro-examples
4. Content tests (≤4 seats, line caps)
5. README positioning + legal/security

## Not Doing
New permanent personas, fifth chamber seat, Grim-scale RP default, stuffing SKILL.md, fake omniscience, docs site, telemetry.
