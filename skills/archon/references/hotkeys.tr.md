# Hotkeys — kısa Türkçe menü (`K` cevabına eklenebilir)

Kullanıcı `K` gönderdiğinde İngilizce tablo yeter; isterse bir satır Türkçe özet:

| Tuş | Ne yapar (kısa) |
|-----|-----------------|
| `W` | Kararı uygula, tekrar tartışma |
| `A` | Cevabı düşmanca sertleştir |
| `S` | Dur; son karar noktasına dön |
| `D` | 2–3 seçenek, birini seç + öldürme kriteri |
| `Q` | Planı en çok değiştiren 2–3 soru |
| `F` | Arıza otopsisi |
| `E` | Anlat / küçült adımları |
| `R` | Domain lensini yeniden seç |
| `X` | Sahnesiz düz verdict |
| `H` | Varsayımlar tablosu |
| `GG` | Atlas modu / ledger |
| `EV` | Archon’u evolve et (rapor) |
| `K` | Bu menü |

Tam davranış: `hotkeys.md`.
