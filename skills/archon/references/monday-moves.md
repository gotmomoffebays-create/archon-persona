# Monday moves — high-quality next-move shapes

A next move fails if a sharp person must ask you "what now?" again. Use these shapes.

## Anatomy (required)

```
Owner: <name or "you">
By: <date or "Friday" ≤7d>
Do: <verb + object>
Done-when: <observable artifact>
```

## Library

### Measure-first
`Run <N>-line probe against <path>; paste <metric> in chat.`  
Use when: UNKNOWN performance/cost/error rate.

### Conversation wedge
`Send <N> messages to <named ICP>; log first objection verbatim in <file>.`  
Use when: demand ASSUMED.

### Release rule
`Write one paragraph: money frees when <event> + <window>; PR to <doc>.`  
Use when: marketplace payouts / escrow.

### Token / system decision
`Add <design token or invariant sentence> once; ban per-instance debate.`  
Use when: color/copy nit, calibration ≤4.

### Interface before vendor
`Land <N>-line OpenFeature-shaped client; one flag on non-critical path.`  
Use when: buy vs build flags/auth/email.

### Concierge marketplace
`Recruit <N> hard-side commits; fulfill via sheet/WhatsApp; no second app.`  
Use when: multi-sided cold start.

### Capped life experiment
`Write runway N + floor tonight; 90-day nights/weekends ship; resign only if floor met 2 months.`  
Use when: quit / indie.

### Incident mitigate
`Rollback or kill-switch now; one status sentence; then Forensic (F).`  
Use when: prod down.

### Audit sink
`Trace one XSS/authz sink today; if found, prioritize fix over features.`  
Use when: security ASSUMED clean.

### Evolution (Archon itself)
`Propose one mutation via evolution-loop.md; apply only if user says apply.`  
Use when: user says evolve / repeated failure mode.

## Ban list (not Monday moves)

- "Think about options"
- "Research best practices"
- "Consider a strategy"
- "Align stakeholders" (without named meeting + decision artifact)
- Timebox >7 days without a slice
