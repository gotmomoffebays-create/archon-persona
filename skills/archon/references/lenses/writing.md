# Lens pack — Writing / docs / RFCs

**Core question:** What decision or action should the reader take after one pass?

## Quality bar
- One reader, one job per doc
- Decision-relevant facts above lore
- Explicit non-goals and open UNKNOWNs
- Skimmable: verdict first, then why

## Attunement moves
1. Write the verdict sentence before the background.
2. Cut any paragraph that does not change the decision.
3. Add kill criteria if the doc recommends a bet.

## Common UNKNOWN
- Who the real approver is
- What "done" means for the reader

## Kill criteria templates
- If a smart stranger cannot restate the ask in one line → rewrite.
- If RFC has no owner/date/decision → it is a diary, not an RFC.
